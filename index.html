Instalação do PaScal Analyzer, TAU e Configuração do PaScal Trace

Configuração completa das ferramentas de análise de escalabilidade, instrumentação e captura de rastros de execução.

Linux (x86_64) · OpenMP PaScal Suite + TAU Commander
Começar instalação ↓ Abrir PaScal Viewer ↗

Diretório base de instalação

Personalize o caminho raiz onde as ferramentas serão instaladas. Todos os comandos abaixo serão atualizados automaticamente.

Exemplo: $HOME/tools ou /opt/hpc

Etapa 01 / Escalabilidade

Instalar o PaScal Analyzer

Baixe o pacote de releases do PaScal Suite e valide a instalação da CLI e da biblioteca de instrumentação.

1Crie o diretório e baixe o release

TERMINAL · DOWNLOAD
sudo apt update
sudo apt install -y g++ gcc swig libpfm4-dev python3-dev python3-pip make
git clone https://gitlab.com/lappsufrn/pascalsuite-analyzer.git
cd pascalsuite-analyzer/
git switch tfeat/tau_integration

2Carregue o ambiente e teste

O script env.sh exporta os binários (pascalanalyzer) e os caminhos de headers/bibliotecas (libpascal) para a sessão atual.

TERMINAL · VALIDAÇÃO
source env.sh
pascalanalyzer -h
Checkpoint: a mensagem de ajuda exibindo as flags (-t, -c, -o, etc.) deve aparecer sem erros de dependência Python.
Etapa 02 / Profiling & Tracing

Instalar e configurar o TAU

O Tuning and Analysis Utilities (TAU) é responsável pela coleta detalhada de eventos e rastros de execução.

1Baixe e extraia o TAU

Caso o sistema já possua um módulo HPC (ex.: module load tau ou via Spack), você pode pular a compilação manual.

TERMINAL · DOWNLOAD TAU
cd $HOME/tools
wget -c https://www.cs.uoregon.edu/research/tau/tau_releases/tau-2.33.2.tar.gz
tar -xzf tau-2.33.2.tar.gz
cd tau-2.33.2

2Configure e compile com suporte a OpenMP / MPI

Ajuste as flags conforme os compiladores disponíveis no seu nó (gcc, mpicc e opari).

TERMINAL · COMPILAÇÃO
./configure -prefix=$HOME/tools/tau -c++=g++ -cc=gcc -fortran=gfortran -mpi -openmp -opari -bfd=download -dwarf=download
make install -j$(nproc)
Usando Spack no cluster? (Alternativa rápida)

Se o Spack estiver configurado no ambiente, instale com:

SPACK
spack install tau +mpi +openmp
spack load tau
Etapa 03 / Integração

Configurar variáveis de ambiente

Unifique o PATH e os Makefiles do TAU com o PaScal Suite para que o pascal_trace funcione de qualquer diretório.

1Adicione as exportações ao seu shell

Inclua o bloco abaixo no final do seu ~/.bashrc (ou carregue antes de cada sessão de análise):

~/.BASHRC · CONFIGURAÇÃO UNIFICADA
# PaScal Suite
source $HOME/tools/pascalsuite-analyzer/env.sh

# TAU Performance System
export TAU_ROOT=$HOME/tools/tau/x86_64
export PATH=$TAU_ROOT/bin:$PATH
export TAU_MAKEFILE=$(ls $TAU_ROOT/lib/Makefile.tau-* | head -n 1)
export TAU_MAKEFILE=/home/brunopaiva/tau-2.35.1/x86_64/lib/Makefile.tau-openmp-opari
export TAU_TRACE=1

2Recarregue e valide os binários

TERMINAL · VERIFICAÇÃO
source ~/.bashrc
which pascalanalyzer tau_exec tau_convert
Checkpoint: os três comandos devem retornar caminhos válidos dentro do diretório de instalação, e echo $TAU_MAKEFILE deve apontar para um arquivo Makefile.tau-... existente.
Etapa 04 / Coleta de Rastro

Executar o pascal_trace

Habilite o modo de tracing do TAU durante a execução instrumentada da aplicação.

1Compile a aplicação com o wrapper do TAU

Para capturar regiões internas de eventos OpenMP no trace, compile utilizando tau_cxx.sh

TERMINAL · COMPILAÇÃO INSTRUMENTADA
tau_cxx.sh -optOpari -fopenmp -O2 app_trace.cpp -o app_trace

2Execute o pascal_trace

Exemplo de execução do PaScal Trace utilizando diferentes configurações.

TERMINAL · EXECUÇÃO COM PASCAL_TRACE
pascalanalyzer ./app_trace -t tau --taub -r 30 -c 1,2,4,8,16 -i "150 300 450 600 750" -o pascal_trace.tar
Atenção ao volume de dados: arquivos de trace crescem rapidamente em aplicações com laços muito curtos e alta frequência de chamadas. Para testes iniciais, utilize entradas moderadas ou configure TAU_THROTTLE=1.
Etapa 05 / Pós-processamento

Conversão e Análise Pós-Trace

Consolide os rastros brutos gerados pelo TAU após o término do pascal_trace e visualize a linha do tempo e métricas.

Após o pascal_trace concluir, o diretório traces_out/ conterá um par de arquivos tautrace....trc e definições de eventos events..edf para cada thread/processo.

1Converta os arquivos de trace

Utilize o tau_convert para exportar o rastro para formatos legíveis (como SLOG-2 para o Jumpshot, OTF2 ou texto estruturado para ingestão no PaScal Viewer):

TERMINAL · MERGE E CONVERSÃO
 # Execute dentro da configuração desejada
tau_convert -dumpname tau.trc events.edf > trace_legivel.txt

2Opções de saída após o pascal_trace

Artefato Gerado Ferramenta / Comando Finalidade na Análise
pasca_trace.tar PaScal Viewer ↗ Avaliar speedup, eficiência e comportamento de escalabilidade das execuções rastreadas.
tau.slog2 tau2slog2 tau.trc events.edf -o tau.slog2 Visualização gráfica de linha do tempo (Gantt) e comunicação/sincronização entre threads no Jumpshot.
trace_legivel.txt tau_convert -dumpname tau.trc events.edf Inspeção textual de timestamps de entrada/saída de funções e parsing.
O que observar após o trace: Visualize de forma detalhada os gargalos de eficiência apontados no PaScal Viewer
